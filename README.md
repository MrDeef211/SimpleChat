# Примерный очерк работы

## Паттерны

Стараемся использовать [Solid](https://metanit.com/sharp/patterns/5.1.php)

**Обязательно** используем "инъекцию зависимостей"

Было бы хорошей идеей использовать паттерн ["прокси"](https://metanit.com/sharp/patterns/4.5.php)

**Минимальный** уровень абстракции и требований к архитиктуре как на САПР у Калентьева

## Архитектура

### Проекты

- Abstractions - Общие для решения интерфейсы, обьекты, команды, DTO
- Connector - реализация доставщика сообщений
- Gui - интерфейс (пока консоль)
- SimpleChat - основное приложение
